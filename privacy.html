Outlier is a Mac-native local AI app. The privacy story is short because the design choice is to keep things on your Mac unless you opt in.

What stays on your Mac

  • Your prompts, chat history, memory, personas, projects, and uploaded files, as long as you use Outlier’s local models. If you switch a chat to a cloud model with your own API key, that chat goes to the provider you chose (see below).
  • Anything Outlier's local models generate. Inference runs on Apple Silicon via MLX, on-device.
  • Your license key is stored at ~/.outlier/license.json with 0600 perms. It goes to one place only, the vendor that issued it: when you activate, and in the re-check at startup and once a day (see below).
  • Bug reports created via Help & Diagnostics. Saved to ~/.outlier/bug_reports/ locally. You decide whether to email them.

What can leave your Mac

Three checks run on their own: the app update check, the license re-check, and the price check when you open an upgrade window. Each is described below, with exactly what it sends. Everything else on this list happens only when you use that feature.

  • The mailing list, if you type an address into a form on outlier.host: most pages here carry a “new models worth running” form. It sends nothing on page load; it posts once, when you press the button. What is stored is the address you typed and which of our sites you sent it from, on our own Cloudflare Worker and D1 database at kerr-subscribe.kerrco.workers.dev: not a marketing SaaS, because dropping one of those onto a site that sells “nothing leaves your machine” would make the claim false in order to collect an email address. No IP address, no user agent, no referer, no fingerprint. That is a statement about the code: the insert binds the address and the source and nothing else, and the worker reads no client header beyond the ones a browser needs to make the request at all. Consent is per site, not per page: every form on outlier.host records the same source, so subscribing from two of our pages is one entry and one email, while the same address given on another of our products is a separate row, and leaving one does not leave the other. Every email carries a one-click unsubscribe. The desktop app never sends this; there is no mailing-list code in the app at all.
  • Model downloads from HuggingFace: when you activate a tier for the first time, the weights download from HuggingFace: Nano, Lite, Quick and Core from huggingface.co/Outlier-Ai, Outlier's own repositories, and Plus and Vision 3.8 from public mlx-community repositories (community conversions of Qwen's models). HuggingFace sees your IP and which repo you fetched. No prompts, no chats, no model output is sent. After the download, the model runs locally forever.
  • Cloud API providers (OpenAI / Anthropic / OpenAI-compatible): only when you explicitly switch to a cloud model in the picker AND provide your own API key. Your prompts and conversation history are sent to that provider per their terms. Your API key is stored locally; we never see it.
  • Anything you connect yourself: an MCP server, a Google Custom Search key, a chat you import from a Gist link: each one receives the requests that feature makes. None of them is set up by default.
  • Agent commands with web off: the agent has no web search, web pages or web-connected tools, and a command that downloads or installs from the internet asks you first, every time; if you approve it, it can reach the internet and nothing else on your Mac.
  • Web search: only when you toggle 🌐 search on for a turn. Sends your search query (not your full prompt history) to DuckDuckGo, Mojeek, and Wikipedia (and, during Deep Research only, additionally Crossref, OpenAlex, StackExchange, and Hacker News / Algolia). Results are then fed back into the local model.
  • App update check: Outlier periodically polls a public GitHub URL for new release metadata. HTTP GET only. Update payloads are cryptographically signed (minisign) and verified before install.
  • The price in an upgrade window: when you open a window that offers Pro, the app asks kerr-lead-agent.kerrco.workers.dev whether the sale is on, so it can show the right price. The request names the site and nothing else: no license key, no device id, nothing you typed. It is never sent on a timer.
  • Founders / Pro license activation: when you paste your license key into Settings → license, the key is sent to the vendor that issued it: live.dodopayments.com for keys bought now, or api.polar.sh for keys bought before 23 August 2026. The app decides from the key itself and sends it to one vendor only, along with a device name so the seat can be counted against your three activations. After that the app re-checks the key with the same vendor at startup and once a day; if the vendor can't be reached, Pro keeps working.

The in-app Privacy Ledger (Settings → Privacy → Privacy ledger) lists the app’s built-in destinations, the license check and the upgrade-window price check included (from version 1.11.866). It is kept by hand from the app’s own network calls, and a test checks it against the hosts the app’s code actually contacts.

What Outlier does NOT do

  • No inference telemetry. We do not log your prompts, model outputs, or which questions you ask.
  • No analytics SDK in the desktop app. (The marketing site at outlier.host runs scripts from other hosts, and this is the whole list: Plausible, which sets no cookies and stores no IP addresses; our own affiliate-referral script, served from a Kerr & Company worker, which only reads a partner code off the link you arrived by; our own mailing-list form script, from the same kind of worker, which sends nothing unless you type an address into a form (described above); our own sale banner script, from a Kerr & Company worker, on every page: it checks whether the sale is still on and remembers in your browser's local storage (key kc-founding-dismissed) that you closed it; and, on the home page only, our own assistant widget, from the same worker, which sends only the messages you type into it. None of them are in the app.
  • Cookies. No tracking cookie is set on this site: Plausible counts visits without cookies, and Meta's (Facebook's) tracking pixel, which used to set a cookie, was removed on 2026-11-06. The referral code and the sale-banner choice described here are kept in your browser's local storage, not in cookies.
  • Affiliate referrals. If you arrive from an affiliate or partner link, the link's referral code is kept in your browser's local storage on this site (key kc_aff) for 30 days and is attached to the checkout link if you buy, so the partner who referred you is credited. This is first-party: it is stored only by this site, is not a cookie, is not sent to any third party by this site, and is not read by any other site. Dodo Payments, the checkout, receives the code as order metadata only when you buy. Clearing your browser's site data removes it.
  • No third-party assets on this site except the scripts listed above. The typefaces are served from outlier.host itself. They used to be requested from Google Fonts (fonts.googleapis.com, fonts.gstatic.com) and Fontshare (api.fontshare.com), which meant simply opening this page exposed your IP address to three servers we do not control. It no longer does: the font files are in this site's own repository and are downloaded from the same host as the page. The desktop app never requested them either, the shipping bundle contains no reference to any of those hosts.
  • No account required to use Free Nano + Lite or BYOK cloud.
  • No automatic crash reporting. Crash logs are saved locally to ~/.outlier/crashes/. You decide whether to email them via the Bug Report flow.
  • No reading your filesystem outside what you explicitly mount as a Project, attach as a file, or grant via macOS file/screen permissions.
