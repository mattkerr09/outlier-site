# Outlier Static Site

The static marketing site for Outlier. `index.html` is hand-written; the ~60 pages
under `seo/` are generated by `_seo_build/scripts/render.py` from CSVs in
`seo/_data/`.

Serve locally with:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment — read this before changing anything about hosting

**This site is NOT served by GitHub Pages.** The previous version of this file
said it was, and that sentence cost a session real work: acting on it, a careful
and correct-looking `_config.yml` was written to stop the build tooling being
served, and it was wholly inert. It had to be reverted.

Verified by asking the server rather than reading this file:

```
$ curl -sI https://outlier.host | grep -i '^server\|^x-service'
server: openresty
x-service: pixie-sh
```

The GitHub Pages API also 404s for this repository. The whole repo is synced to
the host, and **path exclusion lives in the host configuration, outside this
repo** — `_config.yml`, `.nojekyll` and `exclude:` lists have no effect here.

### The consequence that matters

**Every tracked file in this repository is readable over HTTP.** There is no
second line of defence. `scripts/`, `.github/`, `_seo_build/` and `.gitignore`
are all servable, and internal notes committed here have twice been published at
`outlier.host/<filename>` before anyone noticed.

So: **the contents of every tracked file must be safe for a stranger to read** —
including docstrings, test fixtures, error strings and sample data. A prose
cleanup is not enough; a sanitised docstring once shipped alongside a fixture ten
lines below that still quoted the internal line verbatim.

`scripts/no_internal_docs_gate.py` enforces this and is the only thing enforcing
it. CI runs it, along with nine other gates, on every push and hourly.

## Gates

`scripts/*_gate.py` — ten of them, all run by `.github/workflows/gates.yml`.
They check download URLs against the current release, checkout links, link and
asset resolution, the offline proof and its control, deploy freshness against
HEAD, live-status badges, the word floor, internal docs, unstyled classes.

Note what they do **not** cover: every one reads what a page *says*. None can see
spacing, contrast, rhythm or whether anything renders legibly. Those need eyes and
measured geometry from a real browser.
