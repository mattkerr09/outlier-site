How to install local AI on a Mac (step by step)

Outlier · solo-built in Grand Rapids · published 2026-06-09 Last updated 2026-06-09
Quick answer
  • Download the notarized DMG from outlier.host, drag it to Applications, open it.
  • First launch downloads the Nano model (~2.4 GB); after that it runs offline.
  • Requirements: Apple Silicon Mac (M1 or newer), macOS 12+, ~3 GB free disk.
  • No account, no API key — the free tier works immediately.

Installing local AI on a Mac takes about five minutes and no account. You download a signed app, drag it to Applications, and on first launch it pulls a small model so you can start chatting offline. Here's the exact process with Outlier, plus the requirements and a quick sanity check.

Before you start: requirements

  • Apple Silicon Mac (M1, M2, M3, or M4). Intel Macs are not supported.
  • macOS 12 (Monterey) or newer.
  • 16 GB RAM recommended (the free tiers run here); more for larger models.
  • ~3 GB free disk for the first model; more if you add bigger tiers.

Step by step

  1. Download. Go to outlier.host and click Download. You'll get a notarized .dmg (~150 MB).
  2. Open the DMG and drag the Outlier app into your Applications folder.
  3. Launch it. The first open may prompt a macOS Gatekeeper confirmation — it's notarized, so click Open.
  4. First model download. On first launch the app pulls Nano (~2.4 GB) so it has something to run. This needs a connection once.
  5. Start chatting. Type a prompt. You're now running AI locally — no account, no key.

Confirm it's actually local

The proof that it's running on your Mac and not in the cloud: after the first model has downloaded, turn off wifi and send a prompt. It still answers. Chat, model switching, and project memory all keep working offline.

Adding bigger models

The free Nano and Lite tiers cover everyday use. For serious coding or document work, switch to Core 27B (needs a 24 GB+ Mac) — the app downloads it on first use. The largest model, Plus 397B, needs a 64 GB+ Mac. Bigger models mean bigger downloads, so keep an eye on disk space.

Frequently asked questions

Do I need an account to use it?

No. The free tier works with no account and no API key. You only sign in if you upgrade to a paid Pro plan.

Why does the first launch need internet?

Only to download the model weights once. After the model is on your disk, the app runs fully offline — no connection needed for chat or agent work.

Will it run on an Intel Mac?

No. Outlier requires Apple Silicon (M1 or newer) because it uses Apple's MLX framework and the Mac's unified memory. Intel Macs are not supported.
