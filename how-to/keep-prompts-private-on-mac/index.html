How to keep prompts private on a Mac

Last updated 2026-11-15

Quick answer

Outlier can run private AI chat on a Mac without sending your prompts, chat history or files to a cloud model when you use a local model and keep web search off. The model files live on your disk, and replies are computed on Apple silicon. Download the app and a model while connected first. After that, local chat works with Wi-Fi off. Other app features can still make connections, as listed below.

Before you start

You need an Apple silicon Mac on macOS 15 or later, plus enough memory and disk space for your model. Nano and Lite are free with no account. Nano needs at least 6 GB of memory; Lite needs 12 GB. See the Mac setup guide for help choosing a model. Installing the app and downloading model files need a connection. Using those files for local chat does not.

Set up a private local chat

  1. Install while connected. Download Outlier, open the DMG and drag it to Applications. On the first screen, choose a local model and click Download & start. Let the download finish before going offline.
  2. Use a model already on disk. In Settings > Models, look for the green check beside a downloaded tier. Switch to that tier in chat. If you need another model, download it while connected. The model download guide explains the picker.
  3. Choose the offline options. Keep the composer’s web search switch off and use a local model. From Outlier 1.11.1004, turn off Settings > Advanced > Update automatically to stop automatic update checks. Earlier versions have no update switch; their update check can be blocked with Little Snitch or LuLu.
  4. Try with Wi-Fi off. Ask a simple question while connected to confirm the model loads. Then turn Wi-Fi off and ask a new question in the same local chat. If your Mac also has Ethernet or another connection, disconnect that too for this check. The reply should come from the downloaded model. These are steps for you to try; see the offline chat guide for the fuller walkthrough.

What still needs a connection?

Local chat is only one part of the app. The privacy page lists what can leave your Mac and when:

  • Setup and new models. Model files download from Hugging Face. That service sees your IP address and which repository you fetch, but receives no prompts, chats or model output.
  • Cloud models and web search. Switching to a cloud model with your own API key sends that chat’s prompts and conversation history to the chosen provider. Turning web search on sends your search query to search services. Leave it off for local chat without web requests.
  • Update and price checks. The updater checks GitHub unless you turn it off as above. Opening an upgrade window checks whether the sale is on. That price request names the site and sends no licence key, device ID or text you typed.
  • Pro activation and checks. Activate a Pro key while connected. The key and a device name go to the vendor that issued it. Pro then re-checks the key at startup and once a day. Pro keeps working if the vendor cannot be reached.
  • Tools you connect or approve. An MCP server, a Google Custom Search key or a Gist import receives that feature’s requests. With web off, an agent command that downloads or installs from the internet asks you first, every time. Approving it allows that command to reach the internet.

The desktop app has no analytics SDK or inference telemetry. The website has its own scripts and forms, described separately on the privacy page.

Check where requests go

The chat path calls only http://127.0.0.1:8766: the FastAPI sidecar bound to localhost. The Tauri Content Security Policy in tauri.conf.json denies remote connect-src origins by default.

Loopback traffic is the app talking to a process on the same Mac. It is not a cloud request. To inspect connections while online, use a network monitor such as Little Snitch or LuLu. Send a message to a downloaded local model with web search off. No non-loopback packet should carry your message. The update, upgrade-window price and Pro licence checks described above may still appear.

The app’s source is not public, so a network monitor lets you inspect its traffic yourself. Nano, Lite, Quick and Core are Outlier’s own public model repositories on Hugging Face under Outlier-Ai. Plus and Vision 3.8 use public mlx-community conversions of Qwen’s models. Public model files and app source are different things.

You can also open Settings > Privacy > Privacy ledger to read the app’s list of built-in destinations. This list explains the checks; a network monitor shows the connections. For the wider explanation of models stored on disk, read can AI run without the internet?

Common questions

Can I keep AI chats on my Mac?

Yes. Use an Outlier local model with web search off. Your prompts, chat history and files stay on your Mac. A chat you switch to a cloud model goes to that provider.

Do I need the internet before my first offline chat?

Yes. Download the app and a local model while connected. Once the model is on disk, local chat works offline. Downloading another model needs a connection.

Will Pro stop working if its licence check cannot connect?

No. After activation, Pro checks its key at startup and once a day. If the vendor cannot be reached, Pro keeps working.
