What does Outlier Vision run like on MacBook Pro M3 Max?

The pairing under examination is Outlier Vision (19 GB MLX 4-bit, Qwen3.6-35B-A3B base, 32K default context, 24 GB unified memory minimum) on a MacBook Pro M3 Max (Apple M3 Max, 14-16 CPU cores, 30-40 GPU cores, 36|48|64|96|128 GB unified memory, 300-400 GB/s, 2023). Outlier loads this tier as one mlx_lm process inside the bundled FastAPI sidecar. Apple Silicon decode on dense 4-bit weights is bandwidth-bound, so the ceiling on this exact MacBook Pro M3 Max scales as the ratio 300-400 / 800 = 0.38× the published M1 Ultra number.

What is the install path on MacBook Pro M3 Max for Outlier Vision?

The 2023 MacBook Pro M3 Max ships with 36|48|64|96|128 GB of unified memory, so headroom for the 24 GB Outlier Vision requirement is 12 GB on the base SKU. Step-by-step install instructions live on the install guide; the part that varies for this Apple M3 Max machine is that the 19 GB pull from Outlier-Ai/Outlier-Vision-35B-A3B-MLX-4bit over HTTPS lands in ~/Library/Application Support/Outlier/models/vision/ and download time is bandwidth-limited by the network, not by the 14-16-core Apple M3 Max CPU.

What context window can I use on a 36 GB Mac?

The Outlier Vision tier defaults to 32K context and caps at 32K. KV cache scales linearly with context length on dense models, so longer contexts trade headroom for capacity. On a 36|48|64|96|128 GB MacBook Pro M3 Max, the default context is the safe starting point.
