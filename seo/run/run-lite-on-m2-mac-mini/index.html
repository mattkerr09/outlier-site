Run Outlier Lite on Mac mini M2

Last updated 2026-06-18

Quick answer

Outlier Lite on Mac mini M2: needs the higher-RAM SKU. Minimum unified memory required: 12 GB. Disk size: 5.04 GB. Default context window: 32K tokens. On Mac mini M2 the Outlier Lite bandwidth-scaled estimate is ~6.7 tok/s [estimated from family-bandwidth ratio]; derivation: 53.4 tok/s on M1 Ultra × (100 / 800) bus ratio for the Apple M2. Treat as a first-order projection — the Outlier Lite number on this 2023 machine has not been formally measured.

What does Outlier Lite run like on Mac mini M2?

The pairing under examination is Outlier Lite (5.04 GB MLX 4-bit, Qwen3.5-9B base, 32K default context, 12 GB unified memory minimum) on a Mac mini M2 (Apple M2, 8 CPU cores, 10 GPU cores, 8|16|24 GB unified memory, 100 GB/s, 2023). Outlier loads this tier as one mlx_lm process inside the bundled FastAPI sidecar. Apple Silicon decode on dense 4-bit weights is bandwidth-bound, so the ceiling on this exact Mac mini M2 scales as the ratio 100 / 800 = 0.12× the published M1 Ultra number.

How much memory does the model take during generation?

Outlier’s Outlier Lite has a measured peak generation footprint of about 5.5 GB. The Mac mini M2 base configuration ships with 8|16|24 GB unified, and the rule of thumb is to leave roughly 4 GB for the OS and one open browser tab. On Mac mini M2 the Outlier Lite bandwidth-scaled estimate is ~6.7 tok/s [estimated from family-bandwidth ratio]; derivation: 53.4 tok/s on M1 Ultra × (100 / 800) bus ratio for the Apple M2. Treat as a first-order projection — the Outlier Lite number on this 2023 machine has not been formally measured.

What is the install path on Mac mini M2 for Outlier Lite?

The 2023 Mac mini M2 ships with 8|16|24 GB of unified memory, so headroom for the 12 GB Outlier Lite requirement is -4 GB on the base SKU. Step-by-step install instructions live on the install guide; the part that varies for this Apple M2 machine is that the 5.04 GB pull from Outlier-Ai/Outlier-Lite-9B-MLX-4bit over HTTPS lands in ~/Library/Application Support/Outlier/models/lite/ and download time is bandwidth-limited by the network, not by the 8-core Apple M2 CPU.

What context window can I use on a 8 GB Mac?

The Outlier Lite tier defaults to 32K context and caps at 256K. KV cache scales linearly with context length on dense models, so longer contexts trade headroom for capacity. On a 8|16|24 GB Mac mini M2, the default context is the safe starting point.

What works well on this pairing, and what is still rough?

  • The Mac mini M2 (Apple M2, 100 GB/s) is bandwidth-bound on dense 4-bit decode; the throughput ceiling for Outlier Lite on this exact machine is approximately 100 divided by 5.04 GB tokens per second.
  • The 16 GB base SKU of the Mac mini M2 swaps aggressively under the Outlier Lite tier; close Chrome and other RAM-heavy applications before generation.
  • Cold boot of Outlier on a 8-core Apple M2 is roughly 50 seconds while the bundled Python.framework warms; this is documented on the v1.9 backlog under the boot-time investigation thread.

What is the unique number for Outlier Lite on Mac mini M2?

5.04 GB on disk against 8|16|24 GB unified memory means the weights alone consume about 63% of the base SKU’s RAM on the Mac mini M2.

Should I pick a different tier?

For lighter-weight work on this Apple M2, the Nano tier is the next step down and runs visibly faster. For heavier work, the Quick or Core tier is the next step up; check that the 8|16|24 GB SKU you have can fit its weights before installing. The unified-memory explainer works the bandwidth math out, and the bandwidth ratio for Mac mini M2 is 0.12× M1 Ultra reference.
