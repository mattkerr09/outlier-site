What does Outlier Code run like on MacBook Pro M4 Pro?

The pairing under examination is Outlier Code (15.13 GB MLX 4-bit, Qwen3.6-27B base, 64K default context, 24 GB unified memory minimum) on a MacBook Pro M4 Pro (Apple M4 Pro, 12-14 CPU cores, 16-20 GPU cores, 24|48 GB unified memory, 273 GB/s, 2024). Outlier loads this tier as one mlx_lm process inside the bundled FastAPI sidecar. Apple Silicon decode on dense 4-bit weights is bandwidth-bound, so the ceiling on this exact MacBook Pro M4 Pro scales as the ratio 273 / 800 = 0.34× the published M1 Ultra number.

Step-by-step install instructions live on the install guide; the part that varies for this Apple M4 Pro machine is that the 15.13 GB pull from Outlier-Ai/Outlier-Code-27B-MLX-4bit over HTTPS lands in ~/Library/Application Support/Outlier/models/code/ and download time is bandwidth-limited by the network, not by the 12-14-core Apple M4 Pro CPU.

What context window can I use on a 24 GB Mac?

The Outlier Code tier defaults to 64K context and caps at 256K. KV cache scales linearly with context length on dense models, so longer contexts trade headroom for capacity. On a 24|48 GB MacBook Pro M4 Pro, the default context is the safe starting point.
