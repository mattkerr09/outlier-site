Install Outlier

Outlier needs Apple Silicon, M1 or newer, on macOS 15 or later, which is a free update. Intel Macs are not supported. Nano needs 6 GB of memory and Lite needs 12 GB, so both fit a 16 GB MacBook Air. Quick needs 16 GB to load and wants 24 GB. Core and Vision need 24 GB.

  1. Get the DMG from the Outlier download page.
  2. Open the DMG and drag Outlier to Applications.
  3. Open Outlier and download a model tier before going offline.

Or install with Homebrew:

brew install --cask outlier-host/tap/outlier

Activate your licence

To activate Pro, open Settings > license, paste your licence key, then choose Activate. You need a connection for activation. One licence activates on up to 3 Macs at a time. Deactivate one in Settings > licence to move it to another Mac. The pricing page explains Free and Pro.

Lost your key? Email matt@outlier.host with the email you used at checkout. If a Mac is lost or dies before you deactivate it, email and we release the seat. See the licence terms.

Ask for a refund

Refund window: 30 days, no questions asked. Email matt@outlier.host with your order number. Beyond 30 days, refunds are discretionary. Read the payment and refund terms.

Contact support

Email matt@outlier.host to reach Matthew directly. There is no guaranteed response time.

Privacy and network use

When you use local models in Chat or Code mode with web search off, your prompts, chat history, memory, personas, projects, uploaded files and model output stay on your Mac; Auto never starts Research with web search off. If you switch a chat to a cloud model with your own API key, that chat goes to the provider you chose.

The app makes these connections, as listed in the privacy policy:

  • Model downloads come from HuggingFace. It sees your IP address and which repo you fetch.
  • The app checks GitHub for updates on its own.
  • Pro sends your licence key and a device name to the vendor that issued the key for activation. It checks the key again at startup and once a day. If the vendor cannot be reached, Pro keeps working.
  • Opening an upgrade window checks the price. That request names the site, with no licence key, device ID or anything you typed.
  • Web search sends your search query when you turn search on, and Pro's Research reads the web only when search is on: with it off, Auto never starts Research, and choosing Research asks you to turn search on. With web on, the agent can use web pages and web tools. With web off, a command that downloads or installs from the internet asks you first.
  • Cloud models receive prompts and chat history when you choose them and provide your own API key.
  • Services you connect, such as an MCP server, Google Custom Search or a Gist import, receive the requests that feature makes.

The website has its own features: the Ask a question box sends your question to Cloudflare for a cloud AI answer. The mailing list sends the email address you enter and which site you sent it from when you press its button. The desktop app has neither of these website features.

App updates

Outlier has a built-in auto-updater. It checks for new release details on GitHub. Update files are signed and checked before install. Find releases on the Outlier GitHub releases page.

Help FAQ

How do I activate Pro?

Open Settings > license, paste your licence key, then choose Activate. Pro needs a connection to activate the licence.

How many Macs can I use?

One licence activates on up to 3 Macs at a time. Deactivate one in Settings > licence to move it to another Mac.

How do I ask for a refund?

Refund window: 30 days, no questions asked. Email matt@outlier.host with your order number. Beyond 30 days, refunds are discretionary.

Can I use Outlier offline?

Yes. Download a model tier first, then it can answer with the network off. If a later licence check cannot reach the server, Pro keeps working. Web search and cloud models need a connection when you choose to use them.
