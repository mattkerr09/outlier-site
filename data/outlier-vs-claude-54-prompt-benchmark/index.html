Outlier vs Claude — 54-prompt benchmark results (May 2026)

Outlier · published 2026-05-19 Last updated 2026-05-20
Quick answer
  • Outlier Core 27B (local) scored 98.9% overall vs Claude Opus 4.7 (cloud) on 54 head-to-head prompts.
  • All 9 brutal additions hit 100% — chess engine, raft/paxos, ZK proofs, race-condition refactor, needle-in-context, and more.
  • 5/6 warm-up tests identical output; Pomodoro test reached parity after 3 iterations.
  • Remaining 1.1% slack was non-deterministic regex misses (rubric noise), not capability gaps.

This page is the raw benchmark data behind Outlier's parity claims. Same prompts sent to both apps, outputs captured to disk, scored against checklists, no subjective vibes. Methodology, full rubric, and what the bench does and doesn't cover.

Methodology

ModelsOutlier Core 27B (MLX 4-bit) vs Claude Opus 4.7 (cloud API, default settings)
HardwareM1 Ultra Mac Studio, 64–192 GB unified memory, mlx-lm 0.31.3
Date range2026-05-17 to 2026-05-18 (cycle 1 + cycle 2 + cycle 3)
Prompt protocolIdentical wording in both apps. Outlier outputs captured to *.sse + *.txt; Claude outputs to *_claude.txt.
ScoringPer-category objective rubrics (e.g., "valid HTML doctype," "closed script tag," "WebAudio chime present"). Pass/fail per criterion, points summed.
CyclesCycle 1: 6-prompt warm-up. Cycle 2: 45-prompt expansion. Cycle 3: +9 brutal additions = 54 total.
ArtifactsRaw outputs at /private/tmp/parity/*.txt; scoring at parity_bench/outputs/last_score.json

What this benchmark doesn't cover

  • Speed. Bench measured output quality, not tok/s. Claude is 3–5× faster end-to-end.
  • Long context. Prompts capped at ~10k tokens. 50k+ token contexts (where cloud flagships still lead) not tested.
  • Vision. Image input not bench-tested rigorously. Claude's vision stack is currently better.
  • Multi-turn agent runs. Tested single-turn outputs, not extended agentic loops with tool use.
  • Sample size. 54 prompts is a sanity bar, not a publication-grade evaluation. Per-category n is small.

How to reproduce

  1. Install Outlier (Standard tier or higher for Core 27B): outlier.host
  2. Have Claude API access or Claude.ai Pro account
  3. Use the same prompts; capture both outputs to disk
  4. Score against the rubric in parity_bench/outputs/last_score.json (or build your own)

Reproducibility caveat: model outputs are non-deterministic. Re-running these prompts will produce slightly different responses each time; the rubric is what makes the comparison stable.
