Local AI benchmarks for Mac (2026) — Outlier vs Ollama vs LM Studio

Outlier · published 2026-04-30 Last updated 2026-05-20
Quick answer
  • On 7B-class chat: ~70 tok/s on M1 Ultra for Outlier Nano 4B; comparable Ollama / LM Studio numbers in the 60–110 tok/s range depending on model.
  • On 27B-class coding: Outlier Core 27B = 20.7 tok/s, HumanEval pass@1 = 0.8659 (highest in lineup).
  • On 397B-class MoE: only Outlier runs it on 64 GB Macs (V9 paged engine, ~2.1 tok/s, ~11 GB RSS); Ollama and LM Studio can't fit the model.
  • Outlier MMLU numbers σ-qualified vs base: Nano +1.87pp (3.54σ), Lite +1.10pp (2.22σ); Core +0.44pp (1.04σ sub-σ).

This is the raw benchmark data behind comparing the major local-AI options on Apple Silicon in 2026. Outlier numbers are measured on the dev M1 Ultra; Ollama and LM Studio numbers reference public benchmark posts where appropriate.

What the bench doesn't measure

  • Prompt prefill / TTFT. Decode tok/s is steady-state; first-token latency for long prompts can be several seconds even on fast tiers.
  • Tier swap cost. Cold-loading a tier you haven't used recently takes 10s–74s depending on size.
  • Quality on agentic loops. Bench tested single-turn outputs; multi-turn agent quality varies more by app than by model.
  • Vision tasks rigorously. Vision 35B numbers are language-only; image-task quality bench is forthcoming.
  • Long-context (50k+). Bench prompts capped at 4096 prefill; longer contexts are where cloud flagships still lead meaningfully.

How to reproduce

  1. Outlier: download from outlier.host, use the bundled benchmark harness in the app's developer console.
  2. Ollama: ollama run <model> --verbose reports tok/s per response.
  3. LM Studio: chat REPL shows tok/s in the response footer.
  4. MMLU / HumanEval: use lm-evaluation-harness with each model loaded via its native backend.
