Streaming engine benchmarks — Plus + Vision tok/s on Apple Silicon

Outlier · published 2026-05-09 Last updated 2026-05-20
Quick answer
  • V10 (current): Plus 397B at ~2.9 tok/s, 13 GB peak RSS on 64 GB Mac.
  • V10 (current): Vision 35B at ~8 tok/s, 3.5 GB peak RSS.
  • V11 (retired May 2026): 7–10% higher peak tok/s than V10 but pinned 30–55 GB of Metal-wired memory, causing multi-turn regressions.
  • Reason V10 won: V11's LRU cache held experts too aggressively; under multi-turn load peak RSS exceeded V9 baseline.
Engine version note: V11 streaming was removed in Outlier v1.11.71 (2026-05-19) after an M1 Ultra empirical sweep found its 7–10% raw-tok/s advantage was offset by 30–55 GB Metal-wired memory pressure on multi-turn workloads. The current shipping engine is V10. Both engines' numbers are published here for transparency; the V10 numbers are what new installs use.

Outlier's paged-MoE streaming engines (V9, V10, V11) all use the same architectural idea: keep active experts in unified memory, stream cold experts from SSD. They differ in how aggressively they cache, whether they use an LRU, and how they balance peak tok/s against multi-turn memory pressure. This page publishes the raw numbers.

Methodology

HardwareM1 Ultra Mac Studio, 64 GB unified memory, iogpu.wired_limit_mb=57344
Model versionsPlus = Qwen3.5-397B-A17B MLX 4-bit; Vision = Qwen3.6-35B-A3B MLX 4-bit
Inference stackmlx-lm 0.31.3, MLX 0.18.x
Aggregation5-run mean per configuration, fresh process per run (no warm-cache bias)
Soak runs50-turn multi-turn workloads on Plus; 20-turn on Vision
RAM measurementOS-level RSS via ps -o rss=, sampled per token
Date range2026-05-07 (V10 results) to 2026-05-09 (V11 soak verdict), 2026-05-19 (V11 retirement)

The V11 retirement decision: 3% raw-tok/s advantage over V10 evaporated under multi-turn load because the LRU pinned Metal-wired memory aggressively (50-turn peak 14.34 GB exceeded V9 baseline of 13.75 GB). V10's simpler streaming model maintained 13 GB headroom consistently.

Vision had a different tradeoff: V11 was genuinely faster (10.92 vs ~8 tok/s) and lower-memory in single-turn smoke. The retirement still made sense because (a) running V10 across Plus and Vision uniformly is simpler than maintaining two streaming engines, and (b) V11 had ongoing reliability issues uncovered in extended soak runs.

Soak verdict — what passed and what didn't

From the 2026-05-09 soak verdict on V11 across 9 cycles:

  • 135/135 turns coherent — no output collapse, no repetition loops.
  • 0 crashes, 0 segfaults across both Plus N=4 (100 turns) and Vision N=2 (35 turns).
  • Engine-swap V11→V9→V11 round-trip: post-swap tok/s 1.51 vs pre-swap 1.36 — no regression.
  • Idle-resume across 5-minute sleep: clean (no orphan threads, no leaked tensors).
  • Memory pressure on 50-turn Plus: 14.34 GB peak vs smoke 7.34 GB — the regression that drove retirement.

How to reproduce

  1. Install Outlier v1.11.71+ (Pro tier or Founders for Plus 397B): outlier.host
  2. Open Settings → Engine Mode → confirm v10_streaming for Plus.
  3. Run a multi-prompt set; record tok/s from the response footer.
  4. Sample OS RSS with ps -o pid,rss,command -p $(pgrep -f outlier-cli) during generation.

For V11 reproduction (historical): the source-level V11 implementation lives in repo history at commit 525298f^ (one commit before v1.11.71). Not shipped in current DMGs.
