Local AI setup for M1 / M2 / M3 / M4 Mac Studio (2026 guide)

Outlier · solo-built in Grand Rapids · published 2026-05-19 Last updated 2026-05-20
Quick answer
  • M1 Max 32 GB Studio runs Nano + Lite + Quick + Core + Code 27B.
  • M2 Ultra 64 GB adds Vision 35B and Plus 397B (V9 paged inference).
  • 96 GB+ Studio runs Plus 397B in capacity mode for higher tok/s.

The Mac Studio line is a uniquely good fit for local AI: lots of unified memory, fast SSDs, no thermal throttling. This guide walks through which model tiers run comfortably on each Mac Studio generation, what to expect on tok/s, and where the actual cliffs are.

Why Mac Studio matters for local AI

Unified memory on Apple Silicon means the GPU and CPU share the same RAM. There is no model-loading step that copies weights across a PCIe bus to a separate GPU. The whole model — or a streamed slice of it — lives in unified memory and the GPU operates on it in place. That removes one of the bottlenecks PC builds have to engineer around.

The Mac Studio Ultra configurations (M1, M2, M3 Ultra) ship with 64 GB to 192 GB of unified memory and sustained SSD reads of 5–15 GB/s. That combination is what makes a 397B-parameter MoE model viable on a single desktop.

Tier-by-Mac-Studio cheat sheet

Outlier's lineup is seven model tiers. What runs:

The 64 GB tier is the inflection point. Below 64 GB you're constrained to Core 27B and smaller. At 64 GB you can run Plus 397B (the strongest model in the lineup) via the V9 paged engine. Above 96 GB you stop having to stream.

What to buy if you're starting from scratch

For a coding-focused local AI build:

  • Budget pick: M1 Max Mac Studio 32 GB (used market ~$1,400). Runs Core 27B at ~20 tok/s — enough for daily refactor + agent work.
  • Sweet spot: M2 Ultra Mac Studio 64 GB (~$3,500 new or refurb). Adds Plus 397B via streaming for the cases you need the strongest local model.
  • Headroom: M2/M3 Ultra 96+ GB (~$5,000+). Plus 397B runs in capacity mode without streaming overhead.

A 64 GB M2 Ultra is the sweet spot: it runs every tier including Plus 397B via the V9 paged engine. 32 GB handles up to Core 27B.

How fast is local AI on an M1 Ultra?

Measured decode speeds: Nano 4B 71.7 tok/s, Lite 9B 53.4, Core 27B 20.7, and Plus 397B 2.1 in V9 paged inference.

Do newer Mac Studios run faster?

Yes. M2 and M3 Ultra have faster memory and SSDs than M1, so tok/s is higher, though the order of magnitude per tier holds.
