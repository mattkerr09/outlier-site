How to run AI coding offline on Apple Silicon

Outlier · published 2026-05-19 Last updated 2026-05-20
Quick answer
  • Apple Silicon (M1+) with 16 GB+ RAM runs a complete offline AI coding workflow.
  • Core 27B's HumanEval pass@1 is 0.8659 — high enough for real refactors.
  • Turn off wifi and the workflow still runs: chat, agent, file edits, project memory.
  • Trades ~4× speed vs cloud for zero API cost, zero rate limit, zero data exfil.

If you have an M-series Mac and 16 GB or more of RAM, you can run a real AI coding workflow with no internet, no API key, and no cloud. This is what that actually looks like in 2026 — the stack, the tradeoffs, and where local AI still loses to the cloud.

The 30-second setup

The shortest path: download a Mac-native app that bundles a local inference runtime, model weights, and a chat / agent UI. Outlier is one such app. The full sequence:

  1. Download the signed Mac DMG from outlier.host (~150 MB installer).
  2. On first launch, the app pulls Nano 4B (~3 GB) from HuggingFace. After that, no network calls are required for inference.
  3. Turn off your wifi if you want to prove it. Local chat, agent runs, file edits, and project memory all work offline.

Other options exist — Ollama, LM Studio, Jan, llama.cpp directly. They differ in defaults, UI polish, and which models they make easy. The "offline" property is shared across all of them.

What runs on what hardware

Apple Silicon's unified memory means the GPU and CPU share RAM. So the rule of thumb is: your RAM is your usable model size, minus a few GB for the OS and the app.

For coding specifically, Core 27B is the workhorse. Its HumanEval pass@1 is 0.8659 — high enough that the 6-test head-to-head against Claude Opus came out indistinguishable on refactor, reasoning, knowledge, writing, and translation tasks.

What the offline workflow gives up

Two real things:

  • Speed feel. Local Core 27B on an M1 Ultra runs ~22 tok/s. Claude Opus or GPT-5 in the cloud run ~80–100 tok/s. On a 5,000-token response that's roughly 4 minutes locally vs ~1 minute in the cloud. The output ends up the same; the wait is real.
  • Research-grade ceiling. For truly novel research questions, 50k+ token contexts, or PhD-level multi-hop reasoning, the cloud flagships still hold an edge. For the common 95% of asks — code refactors, explanations, comparisons, debugging — Outlier's bench scored 98.9% parity with Claude on 54 tests, with all 9 hardest additions (chess engine, raft/paxos explanation, ZK proofs, etc.) at 100%.

What it gives you back

Nothing leaves the Mac. No rate limit. No API token bill. No model deprecation surprise emails. Code, repos, and chat history stay on your disk. The app works on a plane, behind a corporate firewall, in a coffee shop with bad wifi. Local context retention is essentially unbounded — start a chat in March and pick it up in June without "the context window reset."

For developers under a strict data-handling policy, the offline guarantee is the whole point. For everyone else it's an insurance policy against the day your cloud provider changes the terms.
