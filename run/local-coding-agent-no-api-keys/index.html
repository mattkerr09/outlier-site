How to set up a local coding agent on macOS without API keys

Outlier · solo-built in Grand Rapids · published 2026-05-19 Last updated 2026-05-20
Quick answer
  • A local coding agent runs entirely on your Mac: no API key required.
  • Outlier exposes filesystem, shell, search, and web tools via MCP with approval gates.
  • Core 27B or Code 27B handles daily refactors; Plus 397B available for hard cases.
  • Trades ~4× speed vs Claude Code for zero token bill and full code privacy.

A coding agent is just a chat loop with the ability to read files, write files, and run commands. None of those primitives require a cloud API. Here's how to get a working local coding agent on a Mac in under ten minutes, what it can do, and the honest list of where it still trails Claude Code or Cursor.

The pieces you need

Three things, all of which can live on your Mac:

  1. A local language model with strong code generation. Outlier's Core 27B has a HumanEval pass@1 of 0.8659 — high enough to handle most real refactors. Quick 26B and Code 27B share the same code-tuned config.
  2. An agent loop that takes a user message, runs the model, parses tool calls out of the response, executes the tools, and feeds the results back. Outlier ships this as the "Agent" mode in the app.
  3. Tools the model can call. The standard set: read file, write file, run shell command, search the project, browse the web. Outlier exposes these via MCP (the Model Context Protocol).

Setup, end to end

The shortest version with Outlier:

  1. Download the Outlier DMG from outlier.host, drag to Applications.
  2. On first launch, the app downloads Nano 4B (~3 GB) so it has something to talk to immediately. Bigger tiers download on demand.
  3. Open a project. The app indexes your codebase so the model has context.
  4. Switch to Agent mode. The agent now has filesystem, shell, search, and project memory tools available — gated behind approval prompts.

There are no API keys to configure because there is no cloud API. The model runs locally; the tools run locally; the conversation history sits in ~/.outlier/ on your disk.

What the agent actually does

A typical session looks like this:

User: "Find the function that handles login retries and add exponential backoff."
Agent: searches the project, opens 3 files, picks one, drafts a diff, asks for approval to write, runs the test suite, reports what passed and what didn't.

The agent's effective ceiling depends on which model you point it at. Nano 4B handles small refactors and explanations well; for multi-file work, Core 27B or Code 27B is the right pick. On a 64 GB Mac, Plus 397B is available too but slow (~2.1 tok/s) — useful for the few cases where you need the strongest local model for a complex architectural change.

Where it still trails cloud agents

Three concrete gaps, named honestly:

  • Speed feel. Core 27B at ~22 tok/s vs Claude in the cloud at ~80–100 tok/s. A 5,000-token diff that takes 60s in Claude Code takes about 4 minutes locally.
  • Tier-swap latency. Switching from Nano to Plus mid-session takes about 74 seconds for the cold load. Claude doesn't have this cost because it doesn't physically swap models.
  • Research-grade reasoning. For genuinely novel problems or 50k+ token contexts, the cloud flagships still edge out. For the 95% of day-to-day coding work, Outlier scored 98.9% parity on a 54-test bench against Claude Opus.

What you trade those gaps for: no API token bill, no rate limit, no cloud trip with your repo. For developers in regulated industries, behind corporate firewalls, or just tired of metered tools, that's usually the trade worth making.

Frequently asked questions

Can a coding agent run without any API key?

Yes. A local agent runs the model on your Mac, so there is no cloud API and no key to configure.

What can the local agent do?

Read and write files, run shell commands, search your project, and use web search, each behind an approval gate via MCP.

Which model should power the agent?

Core 27B or Code 27B for daily multi-file work (HumanEval pass@1 0.8659); Plus 397B for the hardest cases on a 64 GB Mac.
