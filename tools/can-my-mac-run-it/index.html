How to read the answer

Fits comfortably means the model's weights plus a 4 GB working set fit in memory, the same test the app uses when it recommends a model. No memory to spare means your memory is exactly the model's minimum: it runs, but other apps will push it into swap. Loads, expect it to swap means the app lets you try it, but it will be slow until you close other apps. Outlier Plus is different: it streams its experts from the SSD, so it runs on a 64 GB Mac, slowly, by design.

Speed is how many tokens a model writes per second once it starts answering. On an M1 Ultra it is our own measurement. On every other Mac it is that measurement scaled by your Mac's memory bandwidth (the M1 Ultra has 800 GB/s), and it says so. The only time we have checked that projection on another Mac, Nano on a 16 GB M4 Air wrote about 32 tok/s, about 3× the 10.8 tok/s the projection gives, so read the estimates as conservative.
