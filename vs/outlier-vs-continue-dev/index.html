Outlier vs Continue.dev: local Mac AI vs an open-source coding agent

Matt Kerr · Outlier · published 2026-07-23 Updated 2026-07-23
Quick answer

Continue is an Apache-2.0, model-agnostic coding agent for VS Code, JetBrains, and the terminal — it ships no model, so whether your code leaves the machine depends on the backend you point it at. Cursor acquired Continue Dev, Inc. in June 2026: the hosted hub is gone and the repo calls itself read-only and no longer maintained. Outlier is a native macOS app for Apple Silicon with its own on-device models, no account, and nothing uploaded — but it's a standalone app, not an editor extension, and its Code 27B tier measured about 45% on a blind SWE-bench Verified slice, below the strongest cloud coding agents.

I'm Matt Kerr, and I build Outlier — so read this as a comparison written by an interested party. These tools solve overlapping problems from opposite directions: Continue is a client you bring a model to; Outlier is a model you bring nothing to.

What Continue is, and what happened to it

Continue is an Apache-2.0 coding agent built by Continue Dev, Inc. from 2023 to 2026. It ships as a VS Code extension (Marketplace and OpenVSX), a JetBrains plugin, and a CLI installed from npm as @continuedev/cli. Continue supplies the chat panel, the edit/apply plumbing, and the agent loop; you supply the model — Ollama on localhost, or any cloud API you hold a key for.

Then, in June 2026, Cursor acquired the company. The vendor's homepage now reads "Continue has joined Cursor," and the README calls the repository "no longer actively maintained" and "read-only for all users" after a final 2.0.0 release that removed anonymous telemetry, pulled out authentication, and fixed bugs. The releases confirm it: v2.0.0-vscode and v2.1.0-vscode both landed 2026-06-19, the CLI stopped at 1.5.47 on 2026-06-18, and JetBrains last shipped v1.0.67 on 2026-03-27. The hosted side isn't deprecated but dead — hub.continue.dev no longer resolves in DNS, and the login flow was retired. The code survives: the repo isn't formally archived, still shows roughly 35,000 stars and 5,100 forks, and Apache-2.0 means anyone can fork it.

What Outlier is

Outlier is a Mac app for Apple Silicon (M1 or later, macOS 12+). It downloads model weights once and runs them on your own GPU. No account, no usage caps, and it works with Wi-Fi off. Seven tiers, from Nano 4B (2.37 GB, 6 GB RAM) to Plus 397B-a17b (209 GB, 64 GB RAM, streaming experts from SSD). For coding, Code 27B is a 15.13 GB download needing 24 GB of RAM. It is not an editor extension — it's a chat app with its own window, the biggest structural difference here.

Where it lives, and where the compute happens

Continue meets you inside the tool you already use — its best design decision. The trade-off: it needs VS Code, a JetBrains IDE, or Node. No native Mac app, no mobile app, and since the hub shut down, no web UI. Outlier is the inverse: a standalone macOS app, Apple Silicon only.

With Continue, where the compute happens is your call — a compliment. Point it at Ollama and the endpoint is http://localhost:11434 — nothing leaves your machine, and Continue's docs frame that as privacy-focused offline assistance. Point it at a cloud API and your prompts and code context go to that third party on that vendor's terms. Its official offline guide covers full air-gapped use: disable anonymous telemetry (which otherwise posts to PostHog), configure a local model, install from a .vsix. Outlier has no such setting to get wrong, because there's no remote option. Continue's locality is a configuration; Outlier's is the architecture.

One gap worth naming: Continue's privacy policy (updated 2026-02-05) says you aren't required to provide personal data to use the open-source software, but it never states whether user inputs or code are used for training, and I found no documented opt-out. It's silent, and silence isn't a yes or a no.

Cost

The extension and CLI were always free; the paid tiers covered the hosted hub and model credits, not the editor tooling. As snapshotted on 2026-06-03: Starter at $3 per million tokens in and out, pay-as-you-go; Team at $20 per seat per month with $10 of credits per seat, private shared agents, access control, and Gmail/GitHub SSO; Company at custom pricing with SAML/OIDC SSO, bring-your-own-key, and SLAs. All historical — those plans can't be bought. Continue today costs whatever your model provider charges, or nothing on local weights.

Outlier's free tier is Nano and Lite, no account. Pro is $20/month or $149/year for all seven tiers including Code 27B, with lifetime licenses from $99 (Founding 200) or $200 (Founders 500).

Agentic ability and repo-scale context

Here's the honest coding receipt. On a blind slice of SWE-bench Verified — real GitHub issues, resolved by an agent that reads a repo, edits files, and runs tests — the local 27B measured ~45% (18 of 40), and Code 27B scores 0.866 on HumanEval. I measured both on my own hardware; they're not leaderboard entries, and they sit below the strongest cloud coding agents. For hard, multi-file, long-horizon agent work a frontier cloud model still wins, and pointing Continue at one is a sensible way to get there.

Continue's agentic ceiling isn't Continue's — it's whichever model you configure. That cuts both ways: strong backend, strong agent; small local model, that model's limits. Same for repo-scale context: on Outlier it's bounded by tier and your Mac's RAM, on Continue by your backend.

Where Continue.dev genuinely wins

  • It's actually open source. Apache-2.0 — permissive enough to fork, relicense, and ship commercially. Outlier's app is not (the weights are public, which isn't the same thing). If client auditability matters, Continue wins outright.
  • Model agnosticism. Run Qwen2.5-Coder through Ollama today, swap to a frontier API tomorrow, with a config change. A single-vendor app can't match that range.
  • It's in your editor. Inline edits, selections, the file you're staring at — no window switching. Better ergonomics than a separate app.
  • It runs where Outlier can't. Windows, Linux, Intel Macs, anything with VS Code or Node.
  • Documented air-gapped operation. An official offline guide, including .vsix install. Few commercial assistants publish one.
  • Battle-tested. Roughly 3.72M VS Code installs and 1.18M JetBrains downloads — though the Marketplace rating is a modest 3.31 from 176 ratings.
  • A clean parting artifact. The final 2.0.0 removed telemetry and auth, making the frozen version a better fork base than the releases before it.

Who should pick which

Pick Continue if you want an open-source client you can read and fork, you need Windows or Linux or an Intel Mac, you live in VS Code or a JetBrains IDE, or you want to route hard problems to a frontier cloud model and easy ones to local weights. Go in knowing you're adopting an unmaintained codebase: no upstream security patches, roughly 935 open issues, stale docs that still present the project as active, and nobody to fix compatibility as model APIs drift.

Pick Outlier if you're on an Apple Silicon Mac and want capable models installed, updated, and supported as a product, with code that never leaves the device because there's no path for it to take. Know what Outlier lacks: no live web search, no image generation, no mobile app, no voice mode, no Windows or Linux build, no cloud sync, no editor extension.

Use both if that fits: Continue in the editor, Outlier for sensitive or offline work. I'd rather you pick the right tool than mine.
