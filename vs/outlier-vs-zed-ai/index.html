Outlier vs Zed AI: on-device Mac assistant vs an AI code editor

Matt Kerr · Outlier · published 2026-07-23 Updated 2026-07-23
Quick answer

Zed is an open-source Rust code editor whose AI runs against cloud-hosted Claude, GPT and Gemini by default — your code leaves the machine unless you configure a local model. Outlier is a standalone macOS app running its models entirely on-device: no account, no caps, nothing uploaded, but it isn't an editor and won't drive your repo. Pick Zed for an agent inside the file you're editing; pick Outlier if your source can't be transmitted at all.

I'm Matt Kerr and I build Outlier, so I've got an obvious stake here — read accordingly and check the sources at the bottom. These two overlap on one thing, helping you write code, and differ on nearly everything else: where they live, which model does the work, whether your source leaves the disk, and what a heavy month costs. Including where Zed is the better tool.

Where each one lives

Zed is a Rust desktop editor from Zed Industries, running natively on macOS, Linux and Windows — built by the people behind Atom and Tree-sitter, and genuinely open source under GPL-3.0-or-later (Apache-2.0 where marked), not a closed shell over a fork. There's a CLI for opening projects and setting Zed as your Git editor. As of mid-2026 Zed's own download and docs pages describe a desktop app only; I found no mobile app or web version. AI shows up in three places: an agent panel for multi-file edits, inline edit prediction as you type, and external agents over ACP (Claude Agent, Codex, OpenCode) plus MCP servers.

Outlier is a native macOS app for Apple Silicon, M1 or later, macOS 12+. No Intel, Windows, Linux or mobile build. It's a standalone assistant window, not an editor — you ask, it answers, you move the code yourself.

Which model does the work

Zed is deliberately vendor-agnostic, with five access paths: models Zed hosts and bills you for, your own API keys, subscriptions you already pay for, gateways like OpenRouter, and local servers via Ollama, LM Studio or llama.cpp. But the models doing the hard reasoning by default are closed-weight — Claude, GPT, Gemini — with the strongest tiers gated to Pro and Business. One exception deserves credit: Zeta, Zed's edit-prediction model, is fine-tuned from Qwen2.5-Coder-7B, released Apache-2.0, with its training dataset published openly. Open weights and open data in a commercial product is rare.

Outlier runs seven tiers locally, from Nano 4B up to Plus 397B-a17b, on Qwen and Gemma bases — six Apache 2.0, Quick under the Gemma Terms of Use. Weights are published at huggingface.co/Outlier-Ai.

Does your code leave the machine?

Zed is cloud-first by default: use an AI feature and your prompt plus code context goes to a provider. Its posture there is strong — zero-retention agreements with Anthropic, Google and OpenAI, no data sales, no training on your inputs by default. Edit-prediction training collection is opt-in and needs three separate conditions met at once: you enable it, the project is detected as open source by its license files, and the files aren't excluded by config. On Business it defaults off, under admin control.

Two caveats, both from Zed's docs. Zero retention carves out provider-designated safety models, which keep data for a limited window (30 days for safety review, not training). And default edit prediction needs a sign-in and cloud round-trip, so cursor context is transmitted continuously as you type unless you switch providers.

Outlier's answer is architectural, not contractual: models run on your Mac, no account, works with Wi-Fi off. Zed's privacy rests on three companies honoring agreements; Outlier's rests on there being no network path.

What it costs

Zed's free Personal plan is $0 forever: 2,000 accepted edit predictions a month, unlimited AI on your own API keys. Pro is $10/month including $5 of tokens; overage bills at API list price +10%, charged at month end or per additional $10 incurred, whichever comes first. Business is $30 per seat per month — no minimum seats, no free trial, no bundled LLM credits at all. The Pro trial runs two weeks with $20 of credits, Opus excluded, and no annual discount is published.

Credit where it's due: on September 24, 2025 Zed moved to token billing and cut Pro from $20 to $10. Companies rarely halve a price, and list +10% is far more legible than opaque prompt quotas.

Outlier's free tier is Nano and Lite, no account. Pro is $20/month or $149/year for all seven tiers, lifetime from $99. No token meter — the marginal cost of a request is electricity.

Agentic ability and repo-scale context

Zed wins this axis and I won't dress it up. Its agent panel edits files across your project, streams edits into view as they land, and hands off to ACP agents or MCP servers. Outlier does none of that — you paste in, you copy out. If you want something that opens files and loops until the tests pass, Zed is built for it and Outlier isn't.

Context is more nuanced. Zed's local path has a real footgun: Ollama defaults to 4,096 tokens unless you set max_tokens per model, quietly truncating large files. Local edit prediction also doesn't support External Agents or Terminal Threads, so local mode isn't at parity with hosted. On my side, context is bounded by the RAM left after weights — Code 27B is a 15.13 GB download needing 24 GB.

My coding numbers, measured rather than claimed: on a blind slice of SWE-bench Verified the local 27B resolved ~45% (18/40), and it scores 0.866 on HumanEval. Those are my own runs, not leaderboard entries, and 45% sits below the strongest cloud agents.

Where Zed's AI genuinely wins

  • It's an editor with an agent in it. Multi-file agentic edits streaming into the buffer you're staring at is a workflow Outlier can't offer. This is the big one.
  • Frontier models on demand. On hard reasoning and long-context synthesis, a hosted Claude or Gemini beats anything fitting in 24 GB of unified memory. My 45% is evidence for that, not against it.
  • Fully auditable. GPL-3.0-or-later means you can read what the AI integration actually does. Outlier publishes weights; the app isn't open source.
  • Cross-platform. macOS, Linux and Windows plus a CLI. Outlier is Apple Silicon only, ruling it out for mixed teams.
  • Cheaper entry. Pro at $10/month is half Outlier Pro, and the free tier is fully functional on your own keys.
  • They're honest about local models. Zed's blog calls frontier hardware "out of reach for consumers" and says local models take more discipline. I respect publishing that instead of burying it.

Who should pick which

Pick Zed if you want AI inside your editor doing agentic multi-file work, if you're on Linux or Windows or a mixed team, if you already pay for a Claude or Copilot subscription to reuse, or if reading your tooling's source matters. When a task needs a frontier model, Zed has one and Outlier doesn't.

Pick Outlier if the code you work on genuinely can't be transmitted — NDA client repos, regulated codebases, unreleased work — and you'd rather that be enforced by architecture than a vendor agreement. Also if you work offline, or want a Mac assistant that handles writing and reasoning alongside code.

Or run both. Zed for repo-scale agentic work on code you're fine sending out, Outlier for the code you're not — and Zed will point its agent panel at a local model too.
