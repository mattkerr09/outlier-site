The five apps in one line each

  • Outlier: Mac-native AI app. Built-in agent loop, MCP tools, project memory, and a custom MLX-based paged-MoE streaming engine. Free Nano + Lite; Pro (the Outlier Lifetime Licence) is a one-time price.
  • LM Studio: A polished GUI for local LLMs. Model catalog browser, chat, OpenAI-compatible API, and now the Bionic agent. Cross-platform; the local app is free.
  • Ollama: A CLI-first runtime for local LLMs that also exposes an OpenAI-compatible HTTP server and ships a basic chat app. llama.cpp backend with GGUF models, plus MLX on Apple silicon (preview since 0.19, March 2026); cross-platform. Free to run locally and MIT-licensed.
  • Msty Studio: A desktop app for local and online models in one window. It drives Ollama, llama.cpp and MLX for you. Free tier, or a paid Aurum seat by the year or for life.
  • Jan: Open-source, ChatGPT-style desktop app on a llama.cpp backend, with an experimental MLX engine. Cross-platform, with a growing extension/MCP ecosystem. Free.

Where a rival is better

LM Studio: more models, and a free agent

LM Studio searches and downloads models from Hugging Face inside the app, and it runs both MLX and GGUF. Outlier ships six tiers and runs MLX only. If the model you want isn't one of those six, LM Studio is the better pick.

Its Bionic agent indexes a folder, edits files, runs shell commands and tests, and splits work into sub-sessions. It's free with local models. I used to count a free local coding agent as something only Outlier had. That's no longer true.

Its local server does more than ours too: images, embeddings and the Responses endpoint, and it can serve other machines on your network. LM Link, in preview, joins your own devices. The paid plans are for cloud models: Bionic+ at $20 a month and Pro at $100.

Ollama: the command line, and everything built on it

Ollama's home page says 9M+ installs a month and shows 186.4K GitHub stars. That reach is the point: most local AI tools already know how to talk to it. It's MIT-licensed, runs headless, and ollama launch starts Claude Code, Codex or OpenCode on a local model. Its API covers chat, embeddings and audio. It has had its own basic chat app since July 2025, and many people pair it with Open WebUI for a fuller one. Local models are free. The cloud plans are Pro at $20, Max at $100 and Team at $500 a month.

Msty Studio: the interface

Msty is the closest to Outlier in shape: a desktop app for people who'd rather not open a terminal. Its window does more than ours. Split Chats puts models side by side, Knowledge Stacks hold your documents, and an MCP Toolbox, a Skills Studio and Real-Time Data search sit alongside. Model Matchmaker suggests models for your machine.

It drives three engines, Ollama, llama.cpp and MLX, and mixes local and cloud models. It runs on Intel Macs from macOS 11, plus Windows and Linux. Its site says "Zero product telemetry". The free tier limits Knowledge Stacks, MCP and projects. Aurum is $149 per user a year, or $349 once for Lifetime, which makes Msty the one rival here with a one-time licence like ours. Outlier vs Msty goes further.

Jan: open source

Jan is an open-source, ChatGPT-style desktop app under Apache 2.0, on Mac, Windows and Linux. It runs llama.cpp with an experimental MLX engine, ships a catalog browser and an OpenAI-compatible API, and Jan Agent keeps memory per project (in preview). Its extension and MCP ecosystem keeps growing. I re-read Jan's docs and GitHub on 9 November for the claims on this page, but not for every row above, so it has no column in the tables.

Where Outlier is different, and the proof

Fine-tune a model on your own Mac

LM Studio, Ollama, Open WebUI and Msty don't mention training in their docs or feature lists. Outlier Pro trains a LoRA adapter for Nano on your Mac, from Settings. It's Nano only for now. How local fine-tuning works.

Bring your Claude, Gemini and Perplexity chats, as well as ChatGPT's

Open WebUI imports ChatGPT exports and says it has no converter for Claude or Gemini. Msty imports only its own export files. LM Studio's and Ollama's docs don't mention import. Outlier reads the export file from all four services, chats and saved memory, and blocks network calls while it works. It's in the free app, under Settings, Data, Import, and in first-run setup. Moving from ChatGPT to local AI.

Models picked, tested and measured

The others hand you a catalog and let you choose. Outlier ships six tiers, and each lists its minimum RAM and a speed we measured: Nano runs at 71.7 tokens a second and Core 27B at 20.7 on an M1 Ultra. Fewer choices, but you know what you're getting before the download starts.

A model bigger than your RAM

Outlier's paged MoE expert streaming runs Plus 397B on a 64 GB Mac (2.0 tok/s, measured on an M1 Ultra); I have not tested the other tools on a model that big. It is slow: 79 seconds to the first token, and it needs 209 GB of disk. Use Core for daily work.

Where Outlier falls short

It runs MLX only, so GGUF files won't load, and there's no open catalog beyond the six tiers. The local API is Pro only, text only, has no embeddings and answers this Mac only. Claude Code works over it, slowly: 86.9 seconds for a one-word reply when we tested it on 6 November (details). PDFs need a text layer, since there's no OCR. It's Mac only: Apple silicon on macOS 15 or later. It has no agent skills yet. The app isn't open source, though four tiers' weights are public on Hugging Face.

Honest verdict per use case

Daily coding agent

Outlier or LM Studio. Outlier's agent loop is built in, you approve each plan before it runs, and your project memory sticks around between sessions. The model lineup is tuned for code (Core 27B scored 0.951 on HumanEval in our August run). LM Studio's Bionic does the same core job and is free with local models, so try both. Jan ships Jan Agent too, and Msty hosts Claude Code, Codex or a local agent in a folder. All of that changed in 2026, and this page said otherwise until it was checked. Ollama is still a backend rather than an agent: its own pitch is to run open models FOR your coding agents, and it lists Claude Code and Codex among its integrations.

Cleanest GUI

Msty, LM Studio or Jan. LM Studio and Jan are both polished, both ship catalog browsers, and both expose OpenAI-compatible APIs. Want the most refined experience for local models? Go LM Studio. Want open source and the extension ecosystem? Jan. Want local and cloud models in one window, with Split Chats? Msty.

Headless backend for scripts and tools

Ollama. If your goal is "I want a local LLM endpoint my Python scripts can hit," the CLI-first design and OpenAI-compatible HTTP server fit well, and the MIT license doesn't hurt. Set it up under launchd and forget it's there.

Running models bigger than your RAM

Outlier, with the speed caveat above. No other app here states it.

Moving off ChatGPT or Claude

Outlier, and the import is free. Your old chats and saved memory come with you, read on your Mac.

Cross-platform requirement

LM Studio, Ollama, Msty or Jan. Outlier is Apple Silicon only, so if you've got a Linux box or a Windows machine in the mix, it's off the table. Msty's docs list Intel Macs too.

The combined-stack pattern

Plenty of serious local-AI users on Mac don't pick one. They run two or three together. Ollama as the headless backend for scripts and CI tools. Outlier as the daily-driver app for coding work. LM Studio, Msty or Jan as a quick chat client when a question pops up. The disk overhead is real (each app pulls its own model files in its own format), but the workflows complement each other instead of competing.

Questions about local AI apps for Mac

What's the best local AI app for Mac in 2026?

It depends on the job. LM Studio for the widest model choice and a free agent, Ollama as a backend for scripts and other tools, Msty for local and cloud models in one window, Jan for open source, and Outlier for a Mac app with tested models, a coding agent, fine-tuning and chat import. Outlier's paged engine runs MoE models bigger than RAM; we have not tested the other tools on this.

Are these local AI tools free?

Ollama and Jan are free and open source (Jan is Apache 2.0; Ollama is MIT and also sells optional cloud plans from $20 a month). LM Studio's local app is free, its Bionic agent included with local models, and its cloud plans start at $20 USD a month. Msty Studio has a free tier, and Aurum is $149 per user a year or $349 once. Outlier has a free Nano + Lite tier, and Pro is a one-time price.

Which local AI apps run GGUF files?

LM Studio, Ollama and Msty run GGUF files through llama.cpp, and so does Jan. Outlier runs MLX only.

Which local AI app can import my ChatGPT or Claude chats?

Outlier imports the export files from Claude, ChatGPT, Gemini and Perplexity, free. Open WebUI imports ChatGPT only, Msty imports its own exports, and LM Studio's and Ollama's docs don't mention import (read 9 November 2026).

Can they run on the same Mac?

Yes. They don't conflict, though each downloads its own model files, so disk usage adds up.
