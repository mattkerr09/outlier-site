Outlier Core 27B vs Claude Opus — a 54-prompt head-to-head

Outlier · published 2026-05-19 Last updated 2026-05-20
Quick answer
  • Same 54 prompts, both apps, side-by-side outputs at /private/tmp/parity/.
  • Outlier Core 27B scored 98.9% overall; all 9 brutal additions 100%.
  • Brutal additions included chess engine, raft/paxos, ZK proofs, race-condition refactor.
  • Where Claude still wins: speed (~4×), long-context (50k+), vision quality.

In May 2026, the same 54 prompts were sent to Outlier Core 27B (running locally on a Mac) and Claude Opus 4.7 (running in the cloud). The raw outputs from both models were saved to disk and graded side by side. This is what the bench found, including the 9 hardest tests where the gap could have shown up.

The setup

Each prompt went through both apps with the same wording. Outputs were captured to /private/tmp/parity/*.txt and graded against an objective rubric per category — for code, things like "valid HTML doctype," "closed script tag," "WebAudio chime present," "keyboard shortcuts wired." Grading was not subjective vibes; it was checklist-based pass/fail.

The 54-test expansion

After the warm-up went green, the bench expanded. Cycle 2 hit 45 tests at 100%. Cycle 3 added 9 brutal tasks:

  • Chess engine with full rules — castling, en-passant, promotion, check, checkmate
  • Paint canvas — brush, color picker, clear
  • Hard combinatorics problem
  • Geometry proof
  • Raft vs Paxos consensus explanation
  • Zero-knowledge proofs — soundness, completeness, SNARKs
  • 6-section blameless post-mortem
  • Race-condition refactor
  • Needle-in-context retrieval (long-context recall)

All 9 hit 100% on Outlier Core 27B. The overall 54-test score was 98.9%. The ~1% slack came from 4 non-deterministic regex misses — model wrote "thread" instead of "single-thread," missed one of multiple SAMHSA helpline phrasings, etc. Not capability gaps; rubric noise.

The honest takeaway

From the bench's own concluding line:

"If you came from Claude for everyday coding / writing / explaining / translating, you would not feel a downgrade on Outlier. The 98.9% bench score reflects that — across 45 real tasks, output quality is indistinguishable."

Where Claude still wins:

  • Speed. Core 27B at ~22 tok/s vs Claude at ~80–100 tok/s. A 5,000-token output takes ~4 minutes locally, ~60 seconds in the cloud.
  • Novel research questions or 50k+ token contexts. The cloud flagships hold an edge here. The bench tested up to ~10k tokens; longer contexts weren't covered.
  • Vision quality. Not bench-tested rigorously yet. Claude's image stack is currently better.

Reproducibility

The raw side-by-side outputs are on the Outlier dev machine at /private/tmp/parity/*_claude.txt and *_outlier.{txt,sse}. The grading rubric is at parity_bench/outputs/last_score.json. Numbers in this article all trace to those artifacts.
