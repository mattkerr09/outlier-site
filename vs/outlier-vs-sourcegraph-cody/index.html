Outlier vs Sourcegraph Cody: on-device Mac AI vs enterprise cloud coding assistant

Matt Kerr · Outlier · published 2026-07-23 Updated 2026-07-23
Quick answer

Sourcegraph Cody is a cloud coding assistant inside VS Code, JetBrains and Visual Studio, sold only as part of Sourcegraph Enterprise — Cody Free and Cody Pro were discontinued on July 23, 2025. Every request sends code snippets to a third-party frontier model like Claude or GPT-5; Enterprise has no local inference. Outlier is a standalone Mac app that runs its models on your own Apple Silicon with no account and nothing uploaded, but it only sees code on your laptop — Cody sees every repository your company has indexed.

Disclosure first: I'm Matt Kerr, and I build Outlier, so every claim here about Cody comes from Sourcegraph's own docs, linked at the bottom. They barely overlap in shape: one is an enterprise platform bolted to a company-wide code index, the other a Mac app you run offline. The useful question isn't which is better, it's which problem you have.

What Sourcegraph Cody is in mid-2026

Sourcegraph's docs describe Cody as an AI coding assistant that uses recent LLMs plus your development context to help you write and fix code. It's marked "Supported on Sourcegraph Enterprise," and that phrase is doing a lot of work.

On June 25, 2025 Sourcegraph announced that Cody Free and Cody Pro would shut down on July 23, 2025, that new signups had already stopped, and that Enterprise Starter would no longer include Cody. Departing users were pointed at Amp. Enterprise customers, the post said, were unaffected, and Sourcegraph remained "fully committed" to that offering.

Since then the signals have been mixed. Cody isn't on Sourcegraph's pricing page or homepage, has no dedicated entry in the 2026 changelog, and goes unmentioned in the December 2, 2025 announcement that Sourcegraph and Amp were splitting into independent companies. The clients still ship, though: VS Code extension v1.155.0 landed 2026-06-17 with 868,377 installs, and the JetBrains plugin has 483,514 downloads.

Where each one lives

Cody is an extension first. Documented clients are VS Code, JetBrains IDEs, Visual Studio (marked Experimental), the web app, and a CLI you install with npm install -g @sourcegraph/cody on Node 20+ — itself "in the Experimental stage for Enterprise accounts." No standalone macOS app or mobile client appears in that list.

Outlier is the opposite shape: a native macOS app for Apple Silicon (M1 or later, macOS 12+). No Intel build, no Windows, no Linux, no iPhone app, no editor extension. You keep a chat window beside your editor and move code yourself. If you want an assistant that edits files in place inside IntelliJ, Cody does that and Outlier can't.

Which model is doing the work

Cody routes to frontier cloud models: Claude Opus 4.8 down to 4.5, Sonnet 5/4.6/4.5 and Haiku 4.5; Gemini 2.5 Pro, 3.1 Pro and 3.5 Flash; GPT-5.4 through GPT-5, GPT-4o, GPT-4.1 and o3. Default chat is Claude Sonnet 4.5. Autocomplete runs on DeepSeek V2 Lite Base and an Autoedits fine-tune of DeepSeek Coder V2 served through Fireworks.ai — open weights, but consumed as a hosted API, not run by you.

Outlier ships seven tiers you download once and run locally: Nano 4B (2.37 GB), Lite 9B (5.04 GB), Quick 26B-a4b (15.61 GB), Core 27B and Code 27B (15.13 GB each), Vision 35B-a3b (19.0 GB), and Plus 397B-a17b (209 GB, streaming experts from SSD at roughly 11 GB peak RSS). Six are Apache 2.0, Quick is under the Gemma Terms of Use, and the weights sit at huggingface.co/Outlier-Ai. Cody's client is no longer open: github.com/sourcegraph/cody returns a 404, and the Apache-2.0 cody-public-snapshot repo is archived, last pushed 2025-08-01.

Does your code leave the machine?

With Cody, always. The FAQ is explicit that inference is remote: Cody sends code snippets, up to 28 KB per request, to a third-party cloud LLM service, and a self-hosted Sourcegraph instance still needs internet access for those calls, which route by default through cody-gateway.sourcegraph.com.

The written guarantees are strong, and I'd rather quote them than paraphrase. Sourcegraph's Cody notice states that Sourcegraph and its partner LLMs don't use code from Cody Enterprise or Cody Pro teams to train models, and that partner LLMs won't retain input or output, embeddings included, beyond the time needed to generate the output. Fine-tuning is opt-in, and enterprises can bypass the Gateway with their own infrastructure.

Outlier's version is structural rather than contractual. Models run on your Mac, with no account and no usage cap, and it works with Wi-Fi switched off — no policy to read and no toggle to find, because there's no server. One caveat on Cody's side: its documented Ollama path, the only local-inference story, says support is Experimental and "available for Cody Free and Pro plans" — the two plans discontinued a year ago. Enterprise has no documented local option.

What it costs, and side by side

On cost: Cody appears nowhere on Sourcegraph's pricing page — the only published figure is an Enterprise plan starting at $16K — and there's no self-serve purchase. Outlier is free for Nano and Lite, $20/month or $149/year for all seven tiers, lifetime from $99.

The honest coding receipts

Here's my number, measured rather than lifted from a leaderboard. On a blind slice of SWE-bench Verified, Outlier's local 27B resolved about 45% — 18 of 40 problems. Code 27B scores 0.866 on HumanEval. Core 27B also matched Claude Opus on 98.9% of rubric checks across a 54-prompt head-to-head, and 100% on the nine hardest prompts.

Forty-five percent is a real result for a 15 GB model on a laptop, and it's also below what the strongest cloud coding agents post. Cody's default is Claude Sonnet 4.5 and its list runs to Opus 4.8; on a genuinely hard multi-file bug, those models beat a local 27B more often than not. I'd rather say that than pretend a quantized model closes a gap that big.

Where Sourcegraph Cody genuinely wins

Cody's moat is real, and a local Mac app can't cross it.

  • Organization-scale context. Cody retrieves from the Sourcegraph index across every remote repository your company has, using keyword search, the Search API, the code graph and @-mentions of files, symbols and repos. For a 5,000-repo org, that's context Outlier can't see — the code isn't on the laptop.
  • Permission-aware retrieval. The FAQ states retrieval ensures only code the user has read permission for is retrieved. That's a hard problem an on-device tool never has to solve, and a hard requirement in regulated environments.
  • No hardware ceiling. Opus 4.8 and GPT-5.4 don't care what Mac you have — no RAM budget, no quantization tradeoff, and the model list refreshes without re-downloading tens of gigabytes.
  • Governance. RBAC roles, admin-chosen models, Context Filters that exclude sensitive paths, and an org-wide Prompt Library. A single-user app has no answer to that.
  • One assistant across a mixed toolchain — VS Code, eleven JetBrains IDEs, Visual Studio and the web, under one policy — and it has shipped since 2023.

Who should pick which

Pick Cody if your company already runs Sourcegraph, your code lives in hundreds of repositories nobody clones locally, you need permission-scoped retrieval and admin governance, and you want frontier-model quality on hard multi-file work. Without an indexed Sourcegraph deployment, the differentiator collapses.

Pick Outlier if you're an individual or small team on Macs, you want code staying on the machine by architecture rather than by contract, you work offline, or you simply can't buy Cody. Outlier has no web search, no image generation, no mobile app, no voice mode, no Windows or Linux build, and no cloud sync. If you need any of those, it's the wrong tool.
