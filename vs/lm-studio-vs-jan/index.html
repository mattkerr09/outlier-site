What I measured in Outlier's local API

A local server has to do more than accept an address in a settings box. I checked Outlier's OpenAI-compatible API through the official openai Python SDK. The first streamed chunk arrived in 0.69 seconds, measured on Outlier 1.11.1012, 17 Nov 2026. That is one response-start measurement, not a promise about every prompt or a speed comparison with Jan or LM Studio.

  • An explicit max_tokens of 40 stopped with finish reason length, measured on Outlier 1.11.1012, 17 Nov 2026.
  • A request over the queue limit failed cleanly with request exceeded max_wall_seconds=30 at 30.0 seconds, measured on Outlier 1.11.1012, 17 Nov 2026.
  • After a client disconnected mid-prompt, the next request answered in 3.4 seconds with no backend restart, measured on Outlier 1.11.1012, 17 Nov 2026.

Those checks tell you something narrow but useful: the server streamed through a standard client, honoured an output limit, returned a timed error and recovered after a disconnect. They do not measure answer quality. They also do not show which rival is faster. I have no matched run of all three apps to offer here.

Outlier's address is http://127.0.0.1:8766/v1. The API is part of Pro. Follow the developer setup to enable it and copy its key. This is a third option for an Apple silicon Mac on macOS 15+, if you want to use Outlier's models from another local tool.

When Jan is the better choice

Jan checked 20 November 2026. Pick it if the right to inspect or change the app matters to you: its repository carries Apache 2.0. It has Windows, Mac and Linux builds. Its Mac requirement is macOS 13.6+, which may matter if you have not moved to macOS 14.

Do not read that older macOS floor as Intel support for local inference. Jan's server docs say its bundled llama.cpp engine does not load models on Intel Macs, and MLX also requires Apple silicon. With default settings its OpenAI-compatible base URL is http://127.0.0.1:1337/v1. Choose by your hardware as well as the licence.

When LM Studio is the better choice

LM Studio checked 20 November 2026. Consider it if you want local models through llama.cpp and MLX, with Bionic as its agent. The download page still offers the classic desktop app as well as Bionic. These are reasons to try it, not evidence that one agent completes more work than another.

Its Free plan is $0.00 with local model support and Bionic Agent; Bionic+ is $20.00 a month and Pro is $100.00 a month. The desktop terms limit use to personal and / or internal business purposes. A zero price does not make those terms an open-source licence.

The Mac requirements are Apple silicon and macOS 14.0 or newer, with 16GB+ RAM recommended. Intel Macs are not supported. Its API guide uses http://localhost:1234/v1 and covers Responses, Chat Completions, Completions, Embeddings and Decisions endpoints.

Choose the client as carefully as the server

Start with the work you need to do. For an open-source desktop app, Jan has a clear licence. For the Bionic agent and the listed API endpoints, read LM Studio's current plans and terms. For Outlier, the evidence above is about server behaviour on one shipped build. None of those facts crowns an overall winner.

Then check where your client sends its requests. A tool that calls the address from your Mac can reach a local server. An address copied into a remote service can point at the wrong computer. Keep the model, client and request path in view before assuming that a local model means a local workflow.

Questions before you choose

Rival details checked 20 November 2026 against the vendor pages linked above.

Which of LM Studio and Jan has an Apache 2.0 app licence?

Jan has an Apache 2.0 app licence on GitHub. LM Studio uses its desktop app terms, which limit use to personal and / or internal business purposes.

Do Jan and LM Studio use the same default API port?

No. Jan documents 127.0.0.1:1337/v1 by default. LM Studio gives localhost:1234/v1 in its OpenAI-compatible API examples.

Does Jan's macOS 13.6 floor mean its engines support Intel Macs?

No. Jan lists macOS 13.6+, but its server docs require Apple silicon for the bundled llama.cpp and MLX engines.

Did the 0.69-second Outlier result compare Jan with LM Studio?

No. It was the first streamed chunk through the official openai Python SDK, measured on Outlier 1.11.1012, 17 Nov 2026. It was not a matched test of the other apps.
