Can Chrome extensions read your ChatGPT chats?

Matthew Kerr · Outlier · published 2026-11-20 Last updated 2026-11-20
Quick answer

Yes. A Chrome extension with access to a chat page can read what that page shows, including your conversation. Review which extensions can access your chat sites and remove those you do not use. Outlier's chat runs in its own app window, but that does not protect against malware already on the Mac.

Page access includes the chat on the page

A browser extension can add useful features to a website. To do that, it may ask to read and change the pages you visit. When that access includes a chat website, the extension can read the conversation shown there. Think about both the chat service receiving your message and the browser software allowed to see it.

The important question is which pages an extension can access. A feature name or an analytics consent prompt does not tell you everything that software can read. Before opening private work in a browser tab, review the extensions that have access to that site.

The case involving over 900,000 users

In January 2026, The Hacker News reported on two Chrome extensions:

  • Chat GPT for Chrome with GPT-5, Claude Sonnet & DeepSeek AI: 600,000 users.
  • AI Sidebar with Deepseek, ChatGPT, Claude, and more: 300,000 users.

Together, they had over 900,000 users. OX Security said the extensions sent user conversations and all Chrome tab URLs to a remote server every 30 minutes. They had asked for consent to anonymous analytics data that would not identify users. The report said both were still downloadable when it was written, and one had lost its Featured badge. The Hacker News, January 2026. Source read 2026-11-20 by our reviewer.

Those facts describe the two named extensions at the time of the report. They do not show that every extension reads chats or sends them away. They do show why checking access matters even when an extension presents itself as a helpful chat tool.

Check the extensions in your browser

  1. Type chrome://extensions into Chrome's address bar. Review the full list, including tools you installed for an old task.
  2. Open Details for each extension. Check its permissions and Site access. Look for access to your chat website or to all sites.
  3. Where Chrome offers a choice, limit site access to the pages that feature needs. If you do not understand why a tool needs access, leave it off while you check.
  4. Remove extensions you no longer use. A smaller list is easier to review when you next need to share private text.

Removing an extension stops future use of that installed copy. It does not recall information already sent elsewhere. If a chat contained a working credential, follow the steps for passwords or API keys pasted into a chat and rotate it with its issuer.

What a desktop chat changes

Outlier's chat runs in its own app window. It is not a web page a Chrome extension can read through site access. Local inference runs on the Mac, so you can work without putting the conversation into a chat website.

This does not protect against malware already on the Mac. Software that can read your screen or local files is a separate risk. A desktop window also does not make text private after you copy it into a website.

Read Outlier's network-use list before choosing features. Use a local model with web tools off for local work. Web search and agent web tools use the network when enabled, and choosing a cloud model with your own API key sends the chat to that provider. You can download Outlier if that app workflow fits your task.
