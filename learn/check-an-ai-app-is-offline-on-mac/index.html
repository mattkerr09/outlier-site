How to check an AI app on your Mac is really offline: 30 seconds with lsof

Matthew Kerr · Outlier · published 2026-11-20 Last updated 2026-11-20
Quick answer

To check Outlier while a local model answers, run the lsof command below in Terminal and read the addresses it lists. Your chats are never on our servers, because we never receive them. The home page's dated capture found no sockets leaving the Mac with web search off; it is a past capture, not a live reading.

The check takes about 30 seconds to start

  1. Open Outlier with a downloaded local model. Turn web search off, keep the chat on that local model and choose Chat or Code mode; Auto never starts Research with web search off.
  2. Ask a harmless question that gives you time to look while the answer is being written.
  3. Open Terminal and paste this command. Run it again while the answer continues.
lsof -a -p $(pgrep -x outlier-cli) -i -n -P

This command asks about Outlier's engine, named outlier-cli. It is not a check of all AI apps. For another app, first identify its model process and any helper processes. A result for the wrong process tells you nothing about the app you meant to inspect.

If the command prints nothing or reports an error, first run pgrep -x outlier-cli on its own. It should return a process number while the engine is running. An empty process lookup is not evidence of an offline answer. Read any lsof error before drawing a conclusion.

Why the -a flag matters

-p selects the process number found by pgrep. -i selects network sockets. The -a is load-bearing: it makes both filters apply together. Without it, lsof ORs the filters and returns every socket on the machine instead. The home page's original capture notes that this wrong command returned 168 then. That number changes as other processes come and go.

-n keeps addresses numeric, and -P keeps port numbers numeric. They make the last column easier to read. Keep the command intact when you copy it.

Read the address, then read the scope

127.0.0.1 is your own Mac. A connection from that address to the same address stays within the machine. Outlier's window talks to its engine on port 8766. Our guide to that local address explains why an offline app has a port at all.

A connection to a remote address is a network connection beyond that local address. It needs an explanation. The listing shows sockets and their endpoints, not the words sent through them. A remote socket alone does not tell you whether it carried a prompt, a download or a licence check. This command also covers the engine process only; it does not inspect every helper or the rest of your Mac.

Existing home page measurement: Captured 2026-11-04 on Outlier 1.11.992 while Core was answering, web search off. A past capture, not a live reading.

It was sampled 22 times across a 24s answer. Sockets leaving this Mac: 0. Every socket the engine held used 127.0.0.1. See the original lsof capture.

Check the known exceptions

Outlier's network-use list describes these separate uses:

  • Model downloads fetch the weights before you can use that model locally.
  • The app checks for updates.
  • Opening an upgrade window checks the current price.
  • Pro checks the licence. These built-in checks carry none of your chat words.
  • Web search sends your search query when you turn it on. Agent web pages and web tools also use the network when enabled.
  • A cloud model sends your chat to the provider you choose when you switch to it with your own API key.

Connections you set up yourself, such as MCP servers, have their own requests. With web off, an agent command that downloads or installs from the internet asks first. Keep the task and settings in your notes when you repeat the check.

What this check does not prove

A sample is a moment. An app can connect between samples. A past capture is not a live reading, and the result above describes that build and that local answer. Repeating it improves what you observe, but does not turn it into a complete record.

It also does not check who can read local files. Malware or a browser extension already on the Mac can read local files it can access. Backups such as Time Machine or iCloud are separate: review where they copy your files and who can reach those copies.

Why ask this question now?

On 11 November 2026, BleepingComputer reported Notion AI transcripts exposed through its infrastructure provider Fireworks AI. BleepingComputer, 11 November 2026, read 2026-11-20 by our reviewer. On 27 October 2026, Stony Brook researchers submitted a study of 42 AI chat platforms that found titles reaching trackers on 21 and verbatim prompts on 9 under the study's test conditions. These are reasons to ask where your words go and to check a particular workflow. The Fireworks explanation covers the provider chain. The tracker study guide compares the two studies. You can download Outlier and repeat the local check on your own Mac.
