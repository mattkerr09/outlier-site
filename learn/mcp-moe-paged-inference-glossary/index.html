MCP, MoE, paged inference — the local-AI glossary

Outlier · published 2026-05-19 Last updated 2026-05-19
Quick answer
  • MCP = Model Context Protocol; a standard for connecting AI agents to tools.
  • MoE = Mixture-of-Experts; only some sub-networks activate per token.
  • Paged inference = streaming weights from SSD on demand, like OS virtual memory.
  • MLX = Apple's GPU array library; the local-AI backend on Mac.

Local AI tooling collected a vocabulary that didn't exist three years ago. This glossary defines the terms in plain language, in the order you're likely to meet them. Use it as a reference when you hit a phrase you don't know.

MCP — Model Context Protocol

An open standard (introduced by Anthropic in 2024) for connecting AI agents to external tools. An MCP server exposes a list of callable functions (read file, query database, send Slack message) plus a schema. An MCP client (the agent app) discovers them and calls them when the model produces a tool call. The point: tools become portable across agent apps. The same filesystem-MCP works in Outlier, Claude Desktop, Continue.dev, and others.

MoE — Mixture of Experts

A neural network architecture where each layer contains many "expert" sub-networks plus a router. For each token, the router picks k experts (for example, 10 of 512 in Qwen3.5-397B) to activate; the rest sit idle. Total parameter count is the sum of all experts; active parameters per token is just the k chosen. Qwen3.5-397B-A17B is MoE: 397B total, 17B active per token.

Paged inference

Running a model whose weights are bigger than RAM by keeping only the actively-used parts resident and reading the rest from SSD on demand. Most useful for MoE models because only a small fraction of weights are needed per token. Outlier's V9 paged engine implements paged inference for Plus 397B on 64 GB Macs.

MLX

Apple's array framework for ML, equivalent to PyTorch / NumPy but optimized for Apple Silicon's unified memory and Metal GPU. Models distributed in "MLX 4-bit" format are quantized for MLX's matmul kernels. All Outlier tiers ship in MLX 4-bit.

GGUF

A model file format used by llama.cpp and tools built on it (Ollama, LM Studio's default backend). Designed for efficient quantization and broad cross-platform support. Different from MLX format; conversions exist but the formats target different inference runtimes.

4-bit quantization

Storing model weights as 4-bit integers (with a small floating-point scaling factor per group) instead of 16-bit floats. About 4× smaller on disk and in memory. Quality regression vs the original 16-bit model is small enough to be invisible on most tasks.

KV cache

The cache of key/value tensors from attention layers, kept across generated tokens so each new token's attention doesn't have to re-read every prior token. Memory cost grows with context length. For long contexts the KV cache can be larger than the model itself.

Tok/s (tokens per second)

The speed metric for inference. Decode tok/s = how many output tokens the model generates per second after the initial prompt prefill. Outlier Core 27B = ~22 tok/s on M1 Ultra; Plus 397B in V9 paged inference = ~2.1 tok/s.

TTFT — time to first token

How long after you hit send before the first token of the response appears. Dominated by prefill (processing the prompt context). For long prompts, TTFT can be several seconds even on fast models. The prefill heartbeat feature in Outlier surfaces this so the UI doesn't go silent.

Cold start / cold load

The time required to load a model's weights into unified memory when it hasn't been used recently. For Plus 397B this is ~74 seconds; for Core 27B it's a few seconds. Hot models respond immediately.

Quantization-aware training (QAT)

Training a model with the eventual low-bit precision in mind, so it learns to be representable in that precision without quality loss. Distinct from post-training quantization, which compresses an already-trained 16-bit model. Ternary models typically use QAT; 4-bit models often don't need it.

Speculative decoding

An inference optimization where a small "draft" model proposes several tokens, then the big model verifies them in one parallel pass. When the draft is right (often!), you generate multiple tokens per big-model pass. Architecturally blocked for Qwen3's hybrid attention setup, which is why Outlier doesn't ship it for Plus / Vision / Core tiers.

Agent loop

The control flow of a coding agent: receive user message → run model → parse tool calls out of the response → execute tools (with approval) → feed results back to model → repeat until done. Outlier's agent loop is the headline of the app's Agent mode; Claude Code's loop is similar.

Frequently asked questions

What does MCP stand for?

Model Context Protocol, an open standard for connecting AI agents to external tools so the same tool works across different agent apps.

What is MoE in AI?

Mixture-of-Experts: a model where a router activates only a few expert sub-networks per token, so active parameters are far fewer than total.

What is paged inference?

Streaming model weights from SSD on demand instead of holding them all in RAM, which lets MoE models larger than your memory run.
